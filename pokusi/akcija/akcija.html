Akcija i promo kod na kartici artikla

Kad je artikl na akciji ili za njega vrijedi promo kod, stara cijena se precrta potezom pera, nova izroni ispod nje, a pokraj njih se utisne voštani pečat s postotkom. Promo kod pretvori dno kartice u odrezak kupona; dodir na kod ga kopira.

Stanja u chatu

  • AkcijaNaxos: precrtana redovna cijena, nova cijena i pečat −20 %.
  • Promo kodRed Tobacco: cijena s kodom, ispod nje „uz kod MRTMX”, a na dnu odrezak „−30 % uz kod MRTMX” s rokom.
  • Akcija + kodDelina: precrtana redovna cijena, cijena nakon akcije i koda, pečat s ukupnim popustom; na odresku piše da kod vrijedi dodatno.
  • Bez popustaHalfeti: kartica izgleda točno kao danas.

Što funkcija šalje

{
  "title": "Mancera ▻ Red Tobacco Eau de Parfum 120 ml",
  "price": "119.00",
  "oldPrice": "149.00",      // akcija (neobavezno)
  "promo": {                   // promo kod (neobavezno)
    "code": "MRTMX",
    "percent": 30,             // ili "price": "83.30"
    "validUntil": "2026-10-31" // neobavezno
  }
}

Ostala polja su ista kao danas. Kod kojem je rok prošao se ne prikazuje. Prava kartica (kartica-artikla.js) nije mijenjana; ovo je njezina kopija u pokusi/akcija/.
